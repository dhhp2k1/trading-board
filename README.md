# 交易看板原型

不用任何付费 API。服务端只用 Python 标准库；独立窗口用 pywebview（调用 Windows 自带的 Edge WebView2，不打包浏览器内核）。

## 运行（Windows）
1. 装 Python 3.9 或更高版本（安装时勾选 "Add python.exe to PATH"）。
2. 双击 `start.bat`。第一次会自动安装 pywebview，之后直接弹出独立窗口，会记住窗口大小和位置。
3. 想用浏览器打开：`python desktop.py --browser`。打包成单个 exe 的方法见 DESKTOP.md。

## 功能
- 顶部全球指数条：A 股四大指数、恒生、道指、纳指、标普、日经、KOSPI、DAX、富时、黄金、原油、离岸人民币、比特币。点击可看图。
- 左侧自选：多分组，点表头排序，悬停出现 ✕ 删除，双击分组名可重命名或删除。
- 添加：输入 600519 / 00700 / 700.HK / AAPL / ^N225 后回车；输入中文或拼音会出搜索建议。
- 导入：支持 TradingView 导出的自选 txt（含 ###分组）、CSV（第一列为代码）、每行一个代码。导出为 TradingView 格式。
- 中间图表：TradingView 开源 Lightweight Charts。周期：分时（含均价线）/ 1、5、15、30、60 分钟 / 日 / 周 / 月；图形：蜡烛 / 空心蜡烛 / 美国线 / 折线；MA5/10/20/60、成交量；十字光标显示开高低收。
- 界面：彭博终端风格（黑底琥珀字、橙色标题栏、等宽字体），顶栏有命令行输入和北京/东京/伦敦/纽约时钟。
- 刷新间隔 2–10 秒可调，可切换红涨绿跌 / 绿涨红跌。设置保存在浏览器本地。

## 已知局限
- 这些都是非官方接口，可能被限流或改版；服务端已加缓存和失败回退。
- "我的 Agent" 按钮是占位，第 4 步接入。

## 更新
程序启动后会自动检查新版本（之后每 30 分钟一次），有新版本时顶栏出现绿色的"↑ 新版本"按钮，点一下即可自动下载、替换文件并重启。也可以在空白处右键 →"检查更新"。
- 自选、设置、资讯翻译缓存都在 %APPDATA%\TradingBoard，更新不会影响。
- 更新来源：GitHub 仓库 dhhp2k1/trading-board（公开），国内优先走 jsDelivr 镜像。
- 发版（开发用）：改 server.py 里的 VERSION/BUILD → `python tools/release.py "更新说明"` → 提交并打 vX.Y.Z 标签推送。
